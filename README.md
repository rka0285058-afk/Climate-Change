# Climate-Change

Interactive climate dashboards (self-contained HTML, open in any browser):

- `year_wise_effects.html`: year-by-year contribution of each driver (CO2, CH4, N2O, ENSO, solar, volcanic) to global temperature
- `temperature_simulation_explorer.html`: Monte Carlo simulation of global temperature to 2050 by scenario
- `sea_level_simulation_explorer.html`: sea-level rise to 2050 driven by the temperature paths
